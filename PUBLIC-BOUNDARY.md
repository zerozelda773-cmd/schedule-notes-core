# Public boundary

Layer 1: this public repository contains independently authored generic Web code, original synthetic fixtures, tests, documentation and a read-only public CI workflow.

Layer 2: real business data and relationships, hospital or purchase identities, customers, employees, sales, plans, activity expenses, photographs, documents and diagnostics remain private and are excluded.

Layer 3: production credentials, signing keys, provider accounts, deployment endpoints, environments and infrastructure remain private and are excluded.

No original private repository source files, history, images, binaries, vendor assets or internal audit evidence are included. The first public commit starts new history. Public code has no production access. These boundaries describe this release, not a redesign of any private product.
