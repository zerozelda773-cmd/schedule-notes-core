# Contributing

Use Node.js 24+ and Python 3.10+. Follow the README install, generate, build, test and static-check steps. Use synthetic tests only. Changes must keep source, identity, period, calculations and output truth explicit: unknown facts must stay unknown.

Do not submit real names, hospitals, purchase IDs, sales, costs, photos, attachments, credentials, private endpoints, production signing resources or material without redistribution rights. A public PR or issue is public information. Report security issues privately using SECURITY.md.

New dependencies require version, source, license, redistribution conditions and notices in THIRD-PARTY.md. New files must enter PUBLIC-MANIFEST.json. Contribution implies you have the right to submit the work under Apache-2.0. This repository has no authority over private product requirements or releases.
