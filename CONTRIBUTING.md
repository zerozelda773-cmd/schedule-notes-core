# Contributing

Contributions are limited to the independent Public Core. Do not copy private product code/history, real names or business records, private attachments, production endpoints, credentials or signing material. Generate fixtures from zero; renaming real data is not sufficient anonymization.

Start with the API/data/adapter contract. Preserve frozen v0.3.0 stable semantics and schema 2 identity/period/null rules. Classify every public member's lifecycle and provide input/output/error/null/identity/period/persistence tests or explicit not-applicable reasons. Commands perform validated changes; queries remain read-only. Diagnostics use enums/counts and stay local.

Run zero-dependency install, generation/provenance, build, all Node/contract/property/headless/package tests, real browser tests, both scanners and synthetic benchmark. Record actual support scope; mocks do not prove persistence or WebView compatibility. Correctness precedes performance. Interactive demo feature changes need before/edit/saved/deleted-or-terminal screenshots; pure headless APIs need full state transition tests.

Register reviewed public files explicitly through tools/update_manifest.py. Review before refreshing hashes; never register internal evidence or discover all workspace files. Package/build whitelists remain closed. Source files require Apache-2.0 SPDX and dependency/license review.

Only reviewed candidates may advance Public main after required Gates. Frozen tags/releases must not change. npm publication, new tags and GitHub Releases require explicit authorization. Do not delete failed evidence or rerun to mask deterministic defects. Historical unknown failures stay unknown until real root-cause evidence exists.
